# Security Policy

The following table indicates the versions of GBZ currently supported with security and stability updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security and privacy are taken seriously. If you discover a security vulnerability or exploit within GBZ, please report it responsibly:

1. **Do not create a public issue**: Please refrain from submitting vulnerability details via public GitHub Issues or discussions.
2. **Contact via Email**: Send an email directly to [mattia.scalise@gmail.com](mailto:mattia.scalise@gmail.com) with the subject line `[SECURITY] GBZ Vulnerability Report`.
3. **Provide Detailed Information**:
   - Detailed description of the vulnerability.
   - Steps or proof-of-concept (PoC) to reproduce the issue.
   - Any relevant logs, ROM formats, or system environment details.
   - Potential impact and mitigation recommendations if known.

### Response Timeline

- **Acknowledgment**: You will receive an initial response acknowledging your report within 48 hours.
- **Assessment**: The issue will be triaged and verified within 5 business days.
- **Remediation**: If confirmed, a patch will be prepared and published in a subsequent release.

## Safe Usage Recommendations

- Only load Game Boy ROM files (`.gb`, `.gbc`) obtained from trusted, legal, and verified sources.
- Keep your .NET runtime environment updated to the latest supported patches.
